# Project 04 – Group Policy: Password Policy and Desktop Restrictions

## Goal

Use Group Policy to enforce password requirements and restrict user desktops.

## Policies configured

### Password Policy

* Minimum length: 8
* Maximum age: 30 days
* Complexity: Enabled

### Desktop Restrictions

* Hide and disable desktop items

## Tasks completed

* Opened Group Policy Management
* Updated Default Domain Policy
* Created Desktop Restrictions GPO
* Linked policy to domain
* Forced gpupdate
* Verified on Windows 11
