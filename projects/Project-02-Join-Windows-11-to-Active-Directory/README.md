# Project 02 – Join Windows 11 to Active Directory

## Goal

Join CLIENT01 to the corp.lab domain and verify DNS connectivity.

## Environment

* Windows Server 2022
* Windows 11
* Domain: corp.lab
* Domain Controller: DC01
* Client: CLIENT01

## Steps completed

* Set DNS on CLIENT01 to DC01
* Verified corp.lab resolves
* Joined CLIENT01 to domain
* Restarted Windows 11
* Logged in with domain credentials
* Tested DNS and internet
